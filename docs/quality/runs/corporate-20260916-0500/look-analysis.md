### 1. サイトマップ

**観測範囲**：添付はトップ1枚、モーション計測もトップのみ。下層は公開中の About・Case を追加確認した。参照URL `sales-dex.jp` は現在 `beyondx-inc.jp` へ転送され、添付のブランド表示とも一致する。以下は **BeyondX の現行構成**として扱う。業務内容は営業支援・営業組織の変革支援であり、ギャラリー分類の `ad` だけで広告会社と判断しない。[参照サイト](https://beyondx-inc.jp/)

グローバルナビの表示順・ラベルは以下。メニュー内に階層はなく、6項目が同列に並ぶ。

| 実際のラベル | 遷移先 | ページが担う役割 |
|---|---|---|
| About | `/about` | 理念・行動指針・組織の強みを説明する |
| Service | `/service` | 営業支援サービスの内容を確認する入口 |
| Company | `/company` | 法人としての基本情報を確認する入口 |
| Recruit | `/recruit` | 採用情報への入口 |
| News | `/news` | お知らせ一覧から個別記事へ進む |
| Case | `/case` | 顧客別の支援内容・成果を比較する |

別枠の常設導線とフッター補完：

- **Contact**：ヘッダー右側のCTA。`/contact`。
- **資料請求はこちら**：画面右下の固定CTA。`/document`。
- **Privacy Policy**：フッターに掲載。`/privacy-policy`。
- ロゴ：トップ `/` に戻る。
- News 配下には個別記事ページが存在する。Case の「Read more」は確認できるが、独立した詳細ページの有無・操作結果は今回未確認。

フッターはグローバルナビ6項目に Contact、Privacy Policy を加えた **8項目**を露出する。[導線の確認元](https://beyondx-inc.jp/)

| 4. About入口 | 理念・強みの詳細へ送る | 左上の欧文タイトル＋日本語副題。左に抽象立体、右に日本語見出し・本文・横長ボタン。下部に薄い大文字の装飾 | 約900px／1.0画面 |
| 5. Case入口 | 顧客実績から信頼を補強 | 左に見出し、右に前後操作。ロゴ・成果見出し・説明を載せた細枠カードが横方向に続く。一覧へのボタン | 約780px／0.9画面 |

### 5. ビジュアルシステム

**配色**

以下は添付JPEGの画素実測。グラデーション・動画・JPEG圧縮を含むため、CSSの指定色そのものではない。

| 系統 | 実測値 | 採取箇所・用途 |
|---|---|---|
| メイン | **`#1F257D`** | トップ画像座標（144,435）。ヒーローの青 |
| メインの暗部 | **`#0B0F2C`** | （720,925）。濃紺背景 |
| アクセント | **`#0581E1`** | 固定資料請求CTA内で採取した青。CTAは単色ではなくグラデーション |
| 背景 | **`#FFFFFF`** | （720,3267）。本文領域の白 |
| 背景の補助色 | **`#1B1E51`** | （720,10784）。フッターの濃紺 |

色の配置ルールは、**ブランド・採用・末尾を青系背景、説明と一覧を白背景、主要CTAを明るい青**とするもの。

**タイポ**

- 欧文大見出し：セリフ系。PCヒーローは実測 **Marcellus／120px**、Aboutのページタイトルは **80px**。
- 日本語：ゴシック系。大見出しは太め、本文は標準ウェイト。丸ゴシックを主軸とする構成ではない。
- 和欧混植あり。欧文を大きく、日本語を小さな副題・説明として添える。
- 日本語見出しは画像比で約32〜48px、本文は約14〜16px相当。こちらは目視推定。
- 後工程では文字サイズだけでなく、**大見出し・説明・補助ラベルの3段階の比率**を共通化する。

**写真・図版**

- 添付トップの表示範囲では、人物・現場・製品の写真は **0点**。
- 主な視覚素材は抽象背景、球体、円弧、立体オブジェクト、顧客ロゴ。
- トップ事例のロゴはDOM上で **5社分**。複製されたカルーセル要素を別素材として数えない。
- Aboutは関係図・同心円の説明図が中心。Caseは16件のロゴ枠が中心。
- 写真の寄り・引きに相当する設計は確認できない。

**余白**

- PC本文幅は概ね **1140〜1150px**、左右余白は **約145〜150px**。
- Aboutの章間は概ね **120〜200px級**の空きを取り、行動指針も大きな縦間隔で区切る。
- Caseのカード間は数px〜十数px程度で、比較対象を連続して読ませる。
- トップ中央の巨大な白場は、通常のセクション余白とは分けて扱う。

### 6. モーション

| 項目 | 実測・判定 | 後工程への指示 |
|---|---|---|
| 支配的リビール | fade-up **250/256＝97.7%**。fade 2、横移動1、zoom 1、other 2 | 主演出は縦移動＋透明度に統一する |
| 移動量 | 元ログの文字要素で `translateY(約89.6px) → 0`、`opacity: 0 → 1` | 大見出しの文字単位演出に相当。本文すべてに適用する必要はない |
| duration | **未取得**。集計は `null`、CSS transition は一部 `0s` | 「0msの演出」と解釈しない。実装案として500〜700msを置く場合は参照実測と区別する |
| easing | 計測値は `ease` | JS内部の補間曲線まで確定した値ではない |
| 発火方式 | `.chars` 要素はクラス追加なしでopacity・transformが変化。Framer由来の要素、Lenisを確認 | 主要文字演出を単純なclassトグルと断定しない。再実装ではIntersection Observer等で同じ見え方を作れる |
| スクロール連動 | **2件**検出。pin・scrub件数は未取得 | 長尺領域をピン固定と決めつけない |
| ヘッダー | 追加DOM確認で固定配置 | 上部中央を維持。スクロール方向による収納・再表示は未確認 |
| ページ遷移 | View Transitions が `in-use` | 遷移の存在は確認。クロスフェード等の具体方式・時間は未計測 |
| 初期ローダー | 自動集計の候補は0件。一方、DOMには0%表示の要素あり | 候補0件を「ローダーなし」の証拠にしない |
| ページ間の演出量 | トップ256件、下層は未計測 | 差分は算出不能。`motion_consistent: true` は1ページだけの集計なので横断的一貫性の証拠にはならない |
| reduced-motion | 通常256件→軽減設定255件。減少は約0.4%。判定は `false` | 参照は実質的に非対応と扱い、継承しない |

**実装時の補完ルール**：軽減設定では移動・文字分割リビール・スムーズスクロール・装飾のスクロール連動を停止し、初期状態から内容を表示する。下層にも共通の控えめな演出を適用するが、参照下層の実測値としては扱わない。

### 7. 借りるべき点 / 借りてはいけない点

**`must_borrow`**

1. **トップと下層の役割分担**：トップは概要と導線、Aboutは理念・強み、Caseは成果の比較に集中させる。
2. **共通シェルの反復**：ヘッダー、固定CTA、下層タイトル、フッター前リンク群を全ページで共通化する。
3. **事例の情報単位を揃える**：ロゴ・社名・成果・要約・詳細導線を同じ順序で提示する。
4. **ページの役割に合わせて密度を変える**：理念ページは広い間隔、事例一覧は連続した行で構成する。
5. **説明図と文章を対応させる**：理念・強みを文章だけで終わらせず、関係図や構造図と組み合わせる。

**`do_not_copy`**

- BeyondX、サービス名、ブランドコピー、ロゴ、顧客ロゴ、独自図版そのもの。
- 添付で約5000pxを占める中央領域の白場。表示状態が未確定。
- reduced-motionへの実質的な非対応。
- 確認した下層にパンくずがない点。
- 英語ラベルのみで事業内容が伝わりにくいナビ。日本市場向け再設計では具体的な日本語ラベルを検討する。
- PC表示で確認した **Contact大型リンクが `/company` を指す不整合**。通常のContact導線は `/contact`。共通部品のリンク先検証が必要。[確認元](https://beyondx-inc.jp/)
- 16件の長い事例一覧に、観測範囲では絞り込みがない点。件数増加時の探索手段は補完する。

### 8. この業種の website に共通しそうな型

この1件から読み取れるのは、**BtoB営業支援会社のサイトで、支援方針・支援内容・成果・会社の実在性を別ページで確認できる構造**である。

- **トップ**：提供価値を示し、検討目的に応じて下層へ振り分ける。
- **About**：サービス品質を支える考え方・組織の仕組みを説明する。
- **Service**：委託範囲を判断する入口を用意する。具体的な説明項目は要追加観測。
- **Case**：顧客名、課題、支援内容、成果を比較可能な単位で示す。
- **Company／News**：会社の基本情報と活動の継続性を確認できるようにする。
- **Contact／資料請求**：相談と情報収集の2種類の入口を用意する。
- **Recruit**：顧客向け検討導線から独立した採用入口を持つ。

青系の抽象背景、大きな欧文、長尺スクロール、写真を使わない表現は、このサイトの選択である。**業界共通の型とするには要追加観測**。
