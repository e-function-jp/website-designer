モーションの確定値

  • 全7ページを「固有本文2グループ＋共通相談帯1グループ」の計3グループに統一。ヒーロー、フォーム相当の状態表示、一覧の個別行、ナビ、パンくずは初期表示する。短いページを長くするための演出追加は禁止。
  • ScrollRevealはfade-up、opacity 0→1、translateY(30px)→0、duration 900ms、easing ease。stagger 0msは未計測の時間差を追加しないための設定。
  • IntersectionObserverはrootMargin「0% 0% -100px 0%」、threshold 0、初回交差時だけ発火。再表示時に初期状態へ戻さない。既存ScrollRevealで不足する指定は共通部品側にオプションとして追加する。
  • ヘッダーはhide。下スクロールでPC translateY(-80px)、モバイルtranslateY(-65px)。上スクロールと上端で0。transition 480ms ease。メニュー展開中・ヘッダー内フォーカス中は退避しない。色変更なし。1pxの高さ差を縮小演出にしない。
  • View Transitionsはoff。スクロール連動1件は対象・移動量が未確定のため追加しない。パララックス、pin、scrub、自動カルーセル、カウンターの数値加算は使わない。
  • prefers-reduced-motion: reduceではリビールを最初からopacity 1、transform none、transition none。ヘッダーは表示位置に固定。スムーズスクロールも停止。JSが実行されない場合も全本文を表示する。

5. 画像生成仕様：8枚に固定

下記8枚だけを生成し、ページ間で再利用する。同じ医院に見えるよう、明るいオーク材・白い壁・淡いグレーの床・彩度を抑えた青のスクラブを統一する。写真内に文字を生成しない。生成人物を実在の院長やスタッフとして紹介しない。全画像の近傍または共通末尾にイメージ表記を置く。

6. 実装完了の判定

  • 全7ページと指定アンカーが実在し、baseを含む出力URLで到達する。全ページで主要CTAと関連リンク2件を確認する。
  • 320px・390px・768px・1440pxで横はみ出し、文字切れ、写真上の文字の埋没がない。200%文字拡大でも操作と本文が欠けない。
  • トップと下層の固有リビールは各2グループ、共通相談帯は1グループ。900ms／ease、ヘッダー480ms／easeを検証する。低減設定とJS無効時は本文が初期表示される。
  • 院長情報・設備仕様・電話・番地・料金・診療時間・採用条件・診療ニュースを追加創作していない。ニュースは常設案内と更新なしの状態を分ける。
  • 予約送信、成功画面、地図、カレンダー、LINE、SNSの架空接続がない。主CTAは初診相談ページへ到達し、受付状態を冒頭で読める。
  • サイト独自テーマ、共通部品のExtract、カタログ実例を実装済みにする。npm run build、npm run check:web、npm run check:catalogで確認し、high・arch-component-reuse・ia-required-page-missingをゼロにする。
