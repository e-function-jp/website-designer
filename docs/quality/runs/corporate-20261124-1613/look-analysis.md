### 1. サイトマップ

グローバルナビのラベルは次の5件。階層はサイト内メニューと各ページへのリンクから確認できる。[^nav]

- **企業情報** — 会社を理解するための入口。
  - **代表メッセージ** — 事業の原点と展望。
  - **私たちの使命** — ミッションの説明。
  - **会社概要・役員** — 法人の基本情報と役員。
- **事業紹介** — 5事業の対象者・概要・各サービスサイトへの導線。
- **プレスルーム** — 対外発表の入口。
  - **ニュース** — お知らせとプレスリリース。
  - **プレスキット** — 報道向け素材。
  - **公開データ** — 公開資料。
- **お問い合わせ** — 連絡窓口。
- **採用情報** — 別ドメインの採用サイトへ移動。

フッターには、上記5件に加え、**awahi magazine／ギフティ採用広報／giftee Tech Blog**、**プライバシーポリシー／情報セキュリティポリシー／セキュリティについて／利用者情報の外部送信について／電子公告**がある。[^footer]

### 2. ページ共通のシェル

- **ヘッダー:** PC幅1440pxではロゴを左上約`(60, 60)`、5件のナビを右上に縦積みする。計測上のヘッダー要素は高さ**240px**で`position: absolute`。固定・縮小・背景色変更はなく、スクロールすると上へ抜ける。営業用CTAはなく、右側に**「動きを停止」**ボタンがある。ハンバーガー関連要素は検出されたが、モバイルでの開閉操作は未確認。
- **フッター:** 濃色の面。上段にロゴ・主要ナビ5件・外部リンク3件・ポリシー5件、下段にSNSアイコンと著作権表示。露出するリンクは**計13件**。住所や電話番号をフッターへ詰めず、会社詳細は「会社概要・役員」に送る。
- **パンくず:** トップにはない。下層はページ冒頭ではなく**フッターの先頭**に「ホーム › 企業情報」「ホーム › 事業紹介」の形で置く。
- **下層ページヘッダ帯:** あり。外側約30pxの白枠を残した、幅約1380px・高さ約330pxの淡色矩形。背景画像はない。左下に英語のページ名、その右に小さな日本語名を置く。

| 2 | Mission・理念への入口 | `Mission`＋「私たちの使命」、短文、矢印ボタン。下方へ大きな空白を取る | 約850px／0.9画面 |
| 3 | 写真群・事業が扱う人間関係の提示 | ケーキ、花、緑、車窓、波、犬など可視6点を大小・段違いで配置 | 約1380px／1.5画面 |
| 4 | Business・事業の全体像 | `Business`＋「事業紹介」、5サービスのロゴ面・対象ラベル・説明・外部リンクを交互配置 | 約1920px／2.1画面 |

### 4. 下層ページの構成

**企業情報：1440×2746px、約3.1画面。** 共通のページヘッダ帯の後、**「代表メッセージ」→「私たちの使命」→「会社概要・役員」**の3行を並べる。各行は左の縦長写真、上部の小さな英語ラベル、右寄せの日本語タイトル・1文説明・矢印ボタンで構成し、約1pxの罫線で区切る。各行は概ね**460～590px**高。最後にパンくず付きフッターが続く。これは内容本文を載せるページではなく、3つの詳細ページへの索引である。[^company]

**事業紹介：1440×4238px、約4.7画面。** 同じページヘッダ帯の後、左に導入文、右に横長写真を置く約600pxの導入部がある。その下に5事業を**各約450～520px**の反復行として掲載する。各行は対象者ラベル、サービス名、数行の説明、矢印ボタン、縦長のロゴ面を持つ。末尾は同じパンくず付きフッター。[^business]

**トップとの差:** 企業情報はトップの約**34%**、事業紹介は約**52%**の長さ。下層は大きな写真群や複数種のレイアウトを減らし、索引行を反復するため**明らかに簡素**である。一方、各行には行き先と判断材料があり、ナビとフッターだけの空ページではない。

### 5. ビジュアルシステム

**配色。** 下記は添付JPEGの平坦部から採取した値であり、CSS原値の保証ではない。

| 用途 | 実測色 | 使用箇所 |
|---|---|---|
| メイン | `#361003` | 見出し、ロゴ、角丸の矢印ボタン |
| アクセント | `#ECA9A0` | ロゴのアスタリスク、種別ラベル等の淡い珊瑚色 |
| 背景 | `#F9F5F4`、`#FFFFFF` | ヒーロー・事業・採用の面と白地を交互に使用 |
| 補助 | `#232323` | 全ページのフッター |

**タイポ。** 和文・欧文ともゴシック系で、明朝や丸ゴシックは見えない。英語は装飾的な小見出しに限らず、**主見出しそのもの**として`Mission`、`Business`、`Company`、`News`、`Careers`を使い、日本語の「私たちの使命」「事業紹介」「企業情報」を隣に小さく添える。企業情報の行では`Message`、`Mission`、`Profile & Team`が小ラベルとなる。ナビは日本語。英語の短い語が見出し幅を取り、日本語の長い説明は別の本文領域に逃がしている。

PCの画像上の寸法から、下層の主見出し`Company`／`Business`は**約40px**、トップのセクション見出しも**約40px**、企業情報の行タイトルは**約18px**。ヒーローの和文コピーは約20pxで字間を広く取る。**SPの実サイズは未実測**のため数値を確定できない。改行は、ヒーローでは「ギフトを起点に、／体温が通った社会をつくる。」と意味で切る。一方、Missionの本文はPC画像上で「…通った社／会をつくる。」と**15文字目の「社」の後で語を割る**箇所があり、この折り方は踏襲しない。

**写真・映像。** トップの中央映像は約**320×480px、2:3、角丸0px**。写真群の可視6点は、人物・贈答の場面・植物・移動風景・水面・動物。約260～540px幅のタイルを2段に置き、横の空きは概ね**110～120px**、上端と高さは揃えない。企業情報の3写真は各約**260×390px、2:3、角丸0px**で左列を揃える。事業紹介の導入写真は約**540×390px**、5つのサービス面は写真ではなくロゴを中央に置く約**260×390px**の矩形である。DOM計測ではトップに画像22件・動画3件、下層2ページに各画像6件・動画0件があり、画像件数にはロゴ等も含む。

**図形・装飾。** 面の切替は白と淡色の矩形が中心。濃茶の矢印ボタンは約**40×40px、角丸約8～10px**。企業情報の3行とニュース5件には約1pxの水平線。現在地を示す小さな珊瑚色の点、外部リンクを示す小さな斜め矢印、ロゴのアスタリスクがある。大きな円・三角・背景グラデーションは見えない。図形そのものの回転・拡大は実測されていない。

**余白。** 広い。PCの外枠約30pxに加え、Missionの本文から写真群まで数百px、企業情報の写真から右側本文まで約**550px**を空ける。下層でも各行を400px超にして情報量を抑えている。

### 6. モーション

- **リビール:** トップは検出8件。支配的なのはフェードで、観測された長さは**1500～2600ms**、イージングは`cubic-bezier(0.5, 1, 0.89, 1)`。見出しのマスク表示と写真の表示を対象にする。企業情報・事業紹介は各**1件**の`clip-path`変化で、**250ms**、`cubic-bezier(0.16, 0.64, 0.32, 1)`。100件超の文字単位演出ではなく、**見出しや画像のまとまり単位**である。[^motion]
- **画像の時間変化:** トップのヒーローでは画像の不透明度が切り替わり、画像倍率が約`1.00～1.10`の間で動く。実測された画像のCSSアニメーションは**8000ms**。`is-shown`、`is-landed`などのclass変化も記録されている。
- **スクロール連動:** 提示値は**28件**だが、計測スクリプト上は「初期画面内で変化した要素」の総数で、ハンバーガーの可視状態やヒーロー画像の切替も含む。したがって、**28件のパララックスを意味しない**。写真・見出しのスクロール量に対する移動率、pinの有無はこのデータでは確定できない。確認できた移動量は画像の倍率変化で、縦方向の変位値はない。ディレクションでは未測定のpinや視差量を指定しない。[^motion]
- **ホバー:** **未検証。** この環境では実ブラウザーが起動できず、カード・リンク・ボタンに実際にポインターを載せた結果を取得できなかった。静止画から色反転、画像拡大、矢印移動を断定しない。実装前に3種を操作確認する必要がある。
- **発火とページ遷移:** `is-shown`等のclass変化とCSSアニメーションが観測され、Lenisが存在する。`viewTransitions`は使用中と検出され、遷移用のCSSキーフレーム名もある。ローダーは検出されない。遷移の具体的な覆い方や時間は未計測。
- **ヘッダー:** 高さ240pxのabsolute配置。スクロールで画面外へ出て、縮小・背景変更はしない。
- **ページ間の量:** トップ**8件**、企業情報**1件**、事業紹介**1件**。トップの検出数は下層の**8倍**。
- **動きを抑える設定:** `prefers-reduced-motion`ではトップのリビールが**8件→0件**となり、対応が確認されている。

### 7. 借りるべき点 / 借りてはいけない点

**must_borrow**

1. トップで「理念→事業→会社→ニュース→採用」の順に案内し、下層で詳細への選択肢を整理する情報階層。
2. 共通の5件ナビ、同じ下層ヘッダ帯、同じフッターとパンくずでページの所属を示すルール。
3. 複数事業を「対象者ラベル→名称→説明→行き先」の同じ情報単位で比較可能にするルール。
4. 写真の密度をトップに寄せ、下層では1行1目的の反復構造に落とす配分。
5. 演出量をトップと下層で変えつつ、reduced motionではリビールを停止するルール。

**do_not_copy**

- `giftee`の名称・サービスロゴ、使命の文言、人物やギフトの写真・映像そのもの。
- 企業情報の索引だけを「会社情報の完成ページ」とみなすこと。詳細3ページまで内容を設計する。
- Mission本文の「社／会」の語中改行。
- 未確認のホバー表現や、28件という値から想像したパララックス・pin。

### 8. この業種の website に共通しそうな型

複数の顧客層を持つ技術系企業では、**企業の使命を示すトップ、対象者別の事業索引、会社情報、ニュース、採用、問い合わせ**という導線は再利用できそうである。事業名だけでなく「個人向け」「法人・従業員向け」など対象者を先に表示すると、初訪問者が行き先を選びやすい。

ただし、**使命を事業説明より約3画面先行させる順序、5事業の数、写真量、フッターにパンくずを置く位置、英語見出しの比率**が業種共通かどうかは、参照1件では判断できない。**要追加観測。**
