参照キャプチャと公開ページを照合し、ナビ・下層構成・ホバー挙動まで実測して設計メモに落とします。

下層ページの自動追跡はサイトの相対 URL 解決に失敗したため、公開 URL を固定して再計測します。併せて実ブラウザでホバー状態を採取します。

PC 実測値に加え、モバイル幅で見出し・ヘッダーの寸法を取り、指定された PC/SP の記述を確定します。

### 1. サイトマップ

グローバルナビは英語ラベルのみで、本文の日本語コピーとは分離している。

- `Concept` — 施設が自然環境とどう関わるか、設計思想と制作チームを説明するページ。
- `Stay` — 室内・設備・宿泊定員を紹介する宿泊詳細ページ。
- `Retreat` — サウナ／休息体験を紹介するページ。
- `Dining` — 食事の選択肢を紹介するページ。
- `Experience` — 周辺自然の体験を紹介するページ。
- `FAQ` — よくある質問。
- `Access` — 住所・地図・来訪方法。
- `News` — 日付付きお知らせ一覧。
- `Contact` — 問い合わせ導線。
- `Reservation` — 外部予約サービスへの CTA。

フッターには上記に加えて、`Top`、`Google Maps`、`Privacy Policy`、`Instagram`、電話番号を露出する。フッター上部には次ページへ送る `Stay` の大型画像 CTA も置く。

### 2. ページ共通のシェル

- **ヘッダー:** 通常の横並びヘッダー帯は持たず、トップでは映像の上にロゴ／ハンバーガー／予約ボタンを重ねる。実測 DOM 上のヘッダー親要素は高さ `0px`、開いたメニュー面は `588px`。PC は相対配置、SP は `fixed` 配置。ロゴは左上、予約 CTA は `Reservation`、PC で `140 × 40px`。SP はハンバーガーから全面オーバーレイのナビを開く構成で、10項目と電話・メールを見せる。
- **フッター:** 3段構成。1段目は大きな画像付き次ページ CTA、2段目は所在地・予約／アクセス／問い合わせ、`Contents` の9リンク、`Social` の Instagram、電話番号を並べる。3段目に `ZINEN` と権利表記。会社概要表はなく、住所は郵便番号から番地まで、連絡先は電話・メールまでを掲載する。
- **パンくず:** なし。下層でも Home › 下層の表記は使わない。
- **下層ページのページヘッダ帯:** 汎用の色帯はなし。`Concept` はベージュ地に左寄せの導入コピー、`Stay` は写真または黒地の導入で開始する。いずれもタイトルだけを載せる短い帯ではなく、導入コンテンツと一体化している。

### 3. トップページの構成

1. **ファーストビュー** — 施設の場所と種別を即時に示す役割。森林・岩・水辺のフルブリード背景動画、`福岡県那珂川市 一棟貸しのサウナ付きリバーサイドヴィラ`、日時・気温・`Scroll` を重ねる。高さは `100vh`、PC 実測 `900px`。
2. **Concept** — 滞在の思想と自然環境を伝える役割。`Concept`、`自然に抱かれ、あるがままに。`、本文、森・渓流・田・建築の写真8点を非対称に散らす。高さ約 `5,800px`、約6.5画面分。
3. **Stay / Retreat / Dining / Experience** — 4カテゴリへの振り分け。各カテゴリは英語大見出し、日本語1文、`View more`、背景いっぱいの写真スライダーで構成する。PC では同一ビューポート内でカテゴリ面が切り替わるため、全体で約9画面分。
4. **News** — 更新性を示す役割。`News`、`View more`、日付＋タイトルの3件一覧。高さ約 `700px`。
5. **FAQ / Contact / Access** — 実務導線を3分割する役割。各項目名と短い説明・矢印を持つカード状リンク。高さ約 `1,000px`。
6. **締めのブランド／次ページ CTA** — `都心からほど近くに、大自然。` と英訳、`View more`、建築外観写真を配置し、`Stay` へ接続する。高さ約 `1,200px`。
7. **フッター** — 所在地、サイトマップ、予約・連絡手段を再提示する。高さ約 `1,200px`。

### 4. 下層ページの構成

**`Concept`（約14.3画面分）**

1. 導入コピー — 清流・里山・宿の位置づけを本文で説明。
2. 風景と体験の叙述 — 朝のコーヒー、焚き火、サウナを文章で連ね、写真3点を挿入。
3. 横スクロール写真列 — 風景・建築の写真6点。`322 × 429px`、`322 × 322px`、`438 × 584px` など縦横比を混在させる。
4. 建築外観 CG — 全幅 `1440 × 3271px` の縦長ビジュアル。
5. Creator — 4名の写真 `211 × 280px` と役割・氏名・紹介文を縦に並べる。
6. 次ページ CTA と共通フッター。

**`Stay`（約15画面分）**

1. 滞在導入 — 宿泊定員と自然環境を説明する本文。
2. 空間紹介 — `Living / Dining`、`Bed Room`、`Play Room`、`Kitchen`、`Terrace`、`Bath` の6項目。各項目は英語見出し、日本語説明、写真スライダー3枚で構成する。
3. 設備詳細 — `宿泊設備`、`キッチン設備`、`アメニティ` の展開項目。
4. `Retreat` への大型 CTA と共通フッター。

**トップとの差:** 両下層とも空白ページではなく、`Concept` は文章・写真・制作者紹介、`Stay` は6空間×写真スライダーで十分に作り込まれている。トップの20.2画面分より短いが、下層も14.3〜15画面分あり、情報量は大きい。差は情報構造で、トップは4カテゴリをスクロール連動で見せるショーケース、下層は1テーマを直列に読む構成である。

### 5. ビジュアルシステム

- **配色:** メインは深い緑灰 `#414A47`、暗部は `#0E1915`、アクセント兼文字・CTA面は砂色 `#E9E2D2`、明背景は `#E7E2D7` と `#FCFCF9`。黒 `#000000` はロゴ・小ラベル・コントラスト用。
- **タイポ:** 日本語は明朝系 `ten-mincho-text`、本文も同系統。英語の主見出しはセリフ寄りの `minerva-modern`、小ラベルはサンセリフ `tt-commons-pro`。和欧混植を前提とする。
  - 英語の主見出し `Stay` / `Retreat` / `Dining` / `Experience` は **PC 70px / SP 48px**。
  - 日本語の主コピー `自然に抱かれ、あるがままに。` は **PC 32px / SP 28px**、行高は PC `49.6px`。
  - ナビ・章ラベルは **PC/SP 16px**、フッターの `Contents` / `Information` / `Social` / `Tel` は **PC/SP 12px**。
  - 英語は主見出しそのもの、グローバルナビ、`View more`、フッターの分類名に使う。日本語見出しの上に飾りとして英語を重ねる方式ではなく、英語をカテゴリ名、日本語を内容説明に分担させる。例は `Stay` と `那珂川を臨む 一棟貸しのリバーサイドヴィラ`。
  - 日本語コピーは意味単位で改行する。例: `自然に抱かれ、／あるがままに。`、`都心からほど近くに、／大自然。`。確認できた範囲に1文字だけを次行へ落とす改行はない。
- **写真:** 人物を主役にせず、森・渓流・田・石・建築外観・室内・サウナを撮る。トップの Concept は自然写真8点を小さな矩形で散らし、宿泊カテゴリは背景いっぱいの建築／室内写真＋下部に4枚のサムネイル。角丸はなく **0px**。トップのカテゴリスライダーは背景写真が概ね `1567 × 971px`、サムネイルは `107 × 59px` を4列、間隔約 `15px` で揃える。
- **図形・装飾:** 森の地形線を模した SVG 4点、丸い進捗マーク、細線、矢印を使う。カテゴリ切替では円形進捗と短い縦線を使い、余白を埋める抽象図形は増やさない。
- **余白:** セクション間は広い。特にトップの Concept は写真間を `80〜300px` 程度ずらし、均等グリッドにしない。本文の塊と次の大写真の間は1画面近く取る。

### 6. モーション

- **支配的なリビール:** トップは 104〜109件で `other` が72〜76件、fade 9〜10件、fade-up 8件、zoom 11件、clip-wipe 3件。基本値は `500〜5000ms`、中央値 `2000ms`。フェード／スライドは `cubic-bezier(0.25, 1, 0.5, 1)` または `cubic-bezier(0.4, 0, 0.2, 1)`、写真スライダーのズームは `5000ms linear`。
- **粒度:** セクション単位ではない。トップは100件超のため、写真、マスク、見出し、本文、サムネイル、進捗線まで要素単位で発火する。カテゴリ面は画像→見出し→本文→`View more` の順に見せる。
- **パララックス／スクロール連動:** あり。トップで43件。Concept の写真群はスクロール量ごとに異なる Y 量で移動し、カテゴリ面ではスクロール進行に合わせて背景色・マスク・表示カテゴリ・円形進捗を切り替える。写真は初期 `scale(1.2)` 付近から縮小しながら表示する。固定（pin）を示すライブラリ実測はなく、実装は通常フローの絶対配置面切替として扱う。
- **ホバー:** 実ブラウザで確認した `Reservation` は、背景が `#E9E2D2` から緑灰へ変わり、文字・矢印が砂色へ反転する。幅 `140px`、高さ約`40px`は維持する。テキストナビの `Stay` / `Retreat` / `Dining` / `Experience` は色・座標の変化を確認できず、下線移動用の擬似要素のみを持つ。
- **発火:** Lenis によるスムーススクロール、Intersection Observer、Alpine の状態管理、CSS transition／Swiper を併用する。GSAP ScrollTrigger の検出はない。
- **ヘッダー:** スクロールで隠れない。トップのみヘッダー状態が切り替わり、メニュー面の展開を持つ。背景色自体は変えない。
- **ページ遷移:** Barba、Swup、View Transitions の利用は検出されない。ローディングロゴ候補はあるが、ページ遷移演出としては確認できない。
- **ページ別の差:** トップ104件、`Concept` 6件、`Stay` 94件。`Concept` は明らかに控えめで、トップとの差は98件。下層間でも演出密度が揃っていない。
- **`prefers-reduced-motion`:** 非対応。通常104件に対し reduced-motion でも110件が検出された。

### 7. 借りるべき点 / 借りてはいけない点

- `must_borrow`
  - トップを「全説明」ではなく、4つの体験カテゴリへ振り分ける情報設計。
  - 英語カテゴリ名と日本語説明文を役割分担させる見出しルール。
  - 下層でも14〜15画面分の固有コンテンツを持たせ、トップとの情報密度を保つ。
  - 住所・予約・アクセス・問い合わせをフッターで再提示し、滞在検討の終端を作る。
  - 写真の角丸・カード枠を使わず、写真サイズと余白の差でリズムを作るルール。

- `do_not_copy`
  - `ZINEN`、那珂川、福岡、制作チーム名、写真、`自然に抱かれ、あるがままに。` を含む固有コピー。
  - 施設固有のサウナ・一棟貸し・外観 CG、住所、予約サービスへのリンク。
  - トップ104件に対して `Concept` 6件となる演出密度の不均衡。
  - `prefers-reduced-motion` 非対応。
  - パンくずを省く構成。多ページ企業サイトでは現在地と上位階層を戻せる必要がある。

### 8. この業種の website に共通しそうな型

- 宿泊・リトリート系では、トップを「施設全体の予約 LP」にせず、`Stay`、食、体験、アクセスへ分ける構成が有効。
- 主要ナビは体験カテゴリを短い固有名で並べ、予約は別色・別領域の CTA にする型が使える。
- 下層は、宿泊なら空間別、コンセプトなら自然環境→思想→制作者／運営情報、という読了順が成立する。
- 写真は人物演出より、周辺環境・建築・室内設備を組み合わせて「行く理由」と「滞在できる根拠」を分担させる。
- スクロール連動を重く使うこと、英語のみの主ナビ、パンくず省略が業種共通かは**要追加観測**。
