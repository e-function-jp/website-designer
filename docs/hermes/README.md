# Hermes handoff

This directory is the version-controlled handoff package for the Website Designer learning loop.

- `HANDOFF.md`: current state, blocker, and restart checklist
- `SESSION_INDEX.md`: resumable session IDs and redacted exports
- `SKILLS.md`: project-skill and Hermes-skill ownership
- `skills/`: repository-owned Hermes skill
- `runtime-snapshots/scripts/`: external Hermes cron scripts at the snapshot time
- `sessions/`: selected Hermes session exports created with `--redact`

The live Hermes database, caches, browser binaries, and credentials are intentionally excluded.
