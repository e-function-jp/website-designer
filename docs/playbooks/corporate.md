# プレイブック: コーポレートサイト

参照サイトを Look 段で解析するたび、観測ログをここに追記して蓄積する。
**これは一般論のガイドではなく、実測の積み上げ**である。1件しか観測していないことは
「要追加観測」と明記し、断定しない。

ディレクション段（`scripts/web-direction.sh`）は Look の生成物を直接読むが、
複数ランを跨いだ知見はここに残す。

## 観測ログ

### run: corporate-20260903-1448 / 参照: EZOBOLIC（corp.ezobolic.jp）

スポーツ・ウェルネス D2C。内部9ページ。GSAP 3.12.2 + ScrollTrigger + Lenis + Lottie。

**IA**

- グローバルナビ9項目を階層なしで5カラムに配置。PC は平置き、SP は
  `Company / Service / Information / Recruit / Store` の5グループに再編して全画面メニューに出す
- トップは「説明ページ」ではなく **5領域への索引**。左に領域名／中央に代表写真／右に下位リンク
  という3点セットを全領域で反復する
- コーポレートサイトを EC の代替にせず、購入は外部 `Store` へ分離。
  サイト側は信頼形成と事業理解に専念させる
- 下層を「大見出し＋写真」で終わらせず分解する
  （Philosophy = Statement / Concept / Vision / Value、Profile = Message / History / 会社概要）
- 各下層末尾に `Related Content` を置き、隣接ページへ戻す。回遊をフッターだけに依存させない

**ビジュアル**

- 配色は無彩色のみ（本文 `#111111` / 罫線・ドット `#000000` / 背景 `#F5F5F5`）。
  色相を持つアクセントは**写真の中だけ**に置く
- 5列グリッドとドットをトップ・下層・フッターで共有し、ページが変わっても座標系を変えない
- 見出し最大 75px、本文 20px / 行高 1.75。本文幅は全幅にせず 5列中2列程度へ制限
- 写真は白背景の商品並べではなく、身体動作・自然表面・現場空間の組み合わせ
- 余白が広い。1セクションが 1.2〜4.5 viewport

**モーション**

- 写真パララックス: GSAP ScrollTrigger、`start: "top bottom"` / `end: "bottom top"` /
  `scrub: true` / pin なし。`-10% → +10%`、`ease: none`
- 慣性スクロール: Lenis（duration 1200ms、指数減衰、タッチでは smooth 無効）
- ヒーロー画像切替: `is-active` class のタイマー切替、1200ms `ease-in-out`、3秒間隔
- ヘッダー: `position: fixed`、高さ121px。**スクロールしても何も変えない**
- SPメニュー: `clip-path` を上端から下方向へ開く、500ms `cubic-bezier(0.19, 1, 0.22, 1)`
- ページ遷移演出なし

**この参照から借りない（参照自身の欠点）**

- モーション量の不均衡（トップ0件 / Philosophy 11件 / Profile 3件）
- `prefers-reduced-motion` をマーキーだけに限定し、パララックス・自動切替を残していること
- 下層ページでパンくずを省略していること
- 表示場所で同一ページのラベルを変えること
  （`Company`/`Profile`、`Laboratory`/`Lab`、`Information`/`News`、`Recruit`/`Recruitment`）
- ヘッダーに問い合わせ CTA が無く、通常フッターにサイトマップも法務リンクも無いこと
- 28px のマーキーに長い住所を常時流し、ナビより高い z-index で固定すること

**一般化できそうな型（要検証）**

- `ブランド思想 → 会社情報 → 商品 → 店舗 → 開発背景 → ニュース → 問い合わせ → 採用 → EC`
  の役割分担。他業種でも成立するかは要追加観測
- 自社店舗・開発拠点を持つ企業では `Stockist` / `Laboratory` を独立ページにする価値がある。
  それらを持たない企業への一般化は**要追加観測**
- 自然写真・巨大な余白・ドットグリッドが業種の型か個別ブランド表現かは**要追加観測**
- 下層をトップ以上の長さと写真量で設計する傾向が同業他社にもあるかは**要追加観測**
