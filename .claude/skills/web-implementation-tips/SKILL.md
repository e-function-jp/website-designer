## 実装前チェックリスト（静的節・手で保守する）

- [ ] ページを書く前に `_site.ts` を書いたか（ナビ・フッター・組織情報の単一情報源）
- [ ] 全ページが `SiteLayout` を使っているか（ヘッダー/フッター/パンくず/JSON-LD/title は自動）
- [ ] `description` はページ固有で40文字以上か（`consist-duplicate-description`）
- [ ] 各ページで `src/components/` を2件以上、サイト全体で6種類以上使ったか
- [ ] 独自テーマを `src/styles/themes/` に起こし、`global.css` の列挙にも足したか
      （列挙し忘れると静かに既定へフォールバックする）
- [ ] 文字色と背景のコントラストは足りているか（**実測で比 1.00 の白地に白文字を出した事故がある**）
- [ ] `loading="lazy"` / `width` / `height` / `alt` を img に付けたか
- [ ] ページ内 `<style>` でアニメーションを書いたなら
      `@media (prefers-reduced-motion: reduce)` の打ち消しを付けたか
- [ ] `<style is:global>` で DaisyUI 共通クラス（`.btn` `.card` 等）を上書きしていないか
      （1ビルドに複数サイトが載るので他サイトを壊す）
- [ ] 「準備中」「coming soon」等の未完成文言を残していないか（**high で検出される**）
- [ ] ディレクションの `data-role="animation"` を全部実装したか。
      import しただけで使っていないコンポーネントは無いか
- [ ] 分割数だけのグリッド（`grid-cols-12` 等）を切ったら、子に `col-span-*` を付けたか
      （付け忘れると子が1カラム幅=約55px に潰れ、本文が1文字ずつ縦に折り返される。
      ビルドも静的チェックも通ってしまう。`arch-grid-span-missing` が high で検出）
- [ ] **見出しだけの細いカラム**を作っていないか
      （`grid-cols-[35%_65%]` の左に見出し1行、右にカード群、のような構図。
      左が見出しの高さしか無く、右の高さぶん空白が空く。見出しを上に置くか、
      左カラムに要約文・補助リンクを入れるか、`lg:sticky top-24` で追従させる）
- [ ] **写真の上に文字を重ねる**なら、重なる範囲に背景（帯・カード・グラデーション）を敷いたか
      （`-mt-20` 等で引き上げて重ねるとき、下が写真のままだと本文が読めない）
- [ ] DaisyUI の `steps` に日本語ラベルを入れたなら、`.step` に幅を与えたか
      （既定は `min-width: 4rem` = 64px。16px の日本語4文字がちょうど64pxなので、
      ラベル同士の隙間が0になり「組織診断商談設計現場定着」と一続きに読める。
      実測 2026-09-18: 同じ指示で3モデルが steps を選び、幅を指定した1つだけが正しく見えた）
