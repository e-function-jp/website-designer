# 単一 HTML で作る没入型プロダクト紹介LP: SOTTO N1（架空の完全ワイヤレスイヤホン）

あなたは熟練のクリエイティブ系フロントエンド開発者である。以下の仕様を **そのまま** 満たす
**自己完結型の単一 `index.html`** を生成しなさい。ビルドなし・フレームワークなし・バンドラーなし。
外部依存は **Google Fonts（`<link>`）/ three.js（importmap）/ Lenis（importmap）のみ**。
**3Dモデルのファイル（glb 等）・画像・動画は一切使わない。** 製品はすべて three.js のジオメトリで組み立てる。

> シリーズ位置づけ: `001` 2D流体 / `002` 粒子モーフ / `003` レイマーチ地形 / `004` 動画とカーソル。
> `005` は **実体のある 3D プロダクトを、スクロールで開き・分解し・組み直して見せる**。
> 構造は otsuka-air.jp（大塚製薬 /zeroz）を実測して得た骨格に倣う（下記 0-1）。

## 0-1. 参照サイトから採る骨格（実測値）

| 観点 | 実測（otsuka-air.jp） | 005 での採用 |
|---|---|---|
| 構造 | `position: fixed` の全画面 div に **canvas 1枚だけ**。その上を sticky のテキスト章が流れる | そのまま採用 |
| 章の尺 | 1章 5,175〜9,430px（約6〜10画面） | 1章 **320svh（約3.2画面）× 6章 ≒ 19画面**（長すぎると1スクロールあたりの変化が乏しくなる） |
| 章の出し入れ | 見出しの `opacity` をスクロール量から直接書き換え（scrub） | そのまま採用（IntersectionObserver の一発表示にしない） |
| 解像度 | canvas の DPR を **1 に固定**（Retina でも 2 倍にしない） | `min(devicePixelRatio, 1.25)`、重ければ 1 → 0.75 へ自動で落とす |
| 色 | 緑と白の2色。**明暗の反転で章を割る** | 暗（#07080a）→ 明（#eef1f4）の反転で前半後半を割る |
| 素材の重さ | GLB 合計 1.6MB・動画はサムネのみ | **外部素材ゼロ**（手続き生成）。尺で没入をつくる |

## 1. ページシェル

- `<html lang="ja">`、`<title>SOTTO N1 — 静けさを、耳の中に。</title>`、日本語の description。
- **フォント:** `Zen Kaku Gothic New`（400/500、和文本文・見出し）+ `Outfit`（300/400/500、英字ラベル・数値）。

- **importmap:**
  ```html
  <script type="importmap">{ "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.170.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.170.0/examples/jsm/",

  ```
  three の addons から使うのは `geometries/RoundedBoxGeometry.js` と `environments/RoomEnvironment.js` の2つだけ。
- **Lenis** `lerp: 0.08`。three の描画ループと **rAF を1本に統合**する。
- **CSS 変数（この色だけ使う）:**

  ```css
  --ink:#07080a; --paper:#eef1f4; --line-d:rgba(255,255,255,0.14); --line-l:rgba(7,8,10,0.12);
  --accent:#9fd8ff;   /* 冷たい水色。使うのは進行インジケータ・選択状態・ANCの波紋だけ */
  --ease:cubic-bezier(0.22,1,0.36,1);
  ```
  文字色は暗転中 `#eef1f4`、明転中 `#07080a` を CSS 変数 `--fg` で切り替える（スクロール進捗から JS が設定）。

## 2. レイヤー構成

| z | 要素 |
|---|---|
| 0 | `.stage`（`position: fixed; inset: 0`）内の `<canvas>` 1枚 |
| 1 | 分解図のラベル（DOM。3D座標を毎フレーム投影して配置）+ 接続線の SVG |
| 2 | `<main>`（各章は `height: 320svh`、内側に `position: sticky; top: 0; height: 100svh` のテキスト） |
| 30 | 右端の章インジケータ（≥1024px） |
| 40 | ヘッダー |

`<main>` の背景は **透明**（キャンバスの色がそのまま背景）。章テキストの読みやすさは、
各 sticky ブロックの背後に `radial-gradient` のスクリムを敷いて確保する（暗転中は黒、明転中は白）。

## 3. 3D（これが本体）

### 3-1. レンダラーと環境
- `WebGLRenderer({ antialias: true, alpha: false })`、`toneMapping = ACESFilmicToneMapping`、`toneMappingExposure = 1.05`、
  `outputColorSpace = SRGBColorSpace`。DPR は 0-1 の表のとおり。
- 環境光は **`RoomEnvironment` を `PMREMGenerator` で1回だけ焼く**（HDR ファイルなし）。`scene.environment` に入れる。
- 追加ライト: キー `DirectionalLight(#ffffff, 2.2)` を `(2.5, 3.5, 2)`、フィル `DirectionalLight(#bcd5ff, 0.6)` を `(-3, 1, -2)`。
- `scene.background` は暗色 `#07080a` と明色 `#eef1f4` を進捗で補間。`fog` は使わない。

### 3-2. 製品の組み立て（すべて手続き生成。単位は m 換算で実寸に近づける）
- **ケース本体**: `RoundedBoxGeometry(0.062, 0.028, 0.050, 6, 0.012)`。**蓋は別メッシュ**
  `RoundedBoxGeometry(0.062, 0.016, 0.050, 6, 0.010)`、ヒンジは背面の辺（`z = -0.025`）。
  蓋の `rotation.x` を `0 → -1.85rad`（約 106°）で開く。
- **イヤホン（左右2つ）**: **ステム付き**にする。丸い頭に短い突起だけだと「棒付きの玉」に見えて、
  イヤホンとして読めない。次を1つの `Group` にまとめる。
  1. `頭` … `SphereGeometry(0.0108, 32, 24)` を `scale(1.26, 0.92, 0.98)` で豆型に。
  2. `ステム` … `CapsuleGeometry(0.0032, 0.0165)` を `scale(1, 1, 0.62)` で**平たく**し、
     頭の外・後ろ寄り `(±0.0050, -0.0150, -0.0016)` に `rotation(-0.14, 0, ±0.20)` で付ける。
     断面が丸いままだと棒に見えるので、必ず平たくする。
  3. `ノズル` … `CylinderGeometry(0.0040, 0.0044, 0.0060)`。`rotation(0.30, 0, ∓1.22)` の Group に入れ、
     頭から真横やや下へ出す。先端に暗いグリル（`CircleGeometry(0.0021)`）。
  4. `イヤーチップ` … `LatheGeometry`（`[0.0026,0.0112] [0.0052,0.0092] [0.0080,0.0048] [0.0078,0.0014] [0.0048,0]`）で
     ノズルを包む傘。色は `#a9aeb6`（白いシェルと見分けがつく濃さにする）。
  5. `マイク口` … `TorusGeometry(0.0034, 0.0007)` をステム下端に。
  6. `センサー` … `CircleGeometry(0.0016)` の暗い点を頭の内側の面に（向きの手がかり）。
- **分解用の内部パーツ**（分解章でだけ表示・不透明度を上げる）:
  `ドライバー` `CylinderGeometry(0.0050, 0.0050, 0.0030)`、`バッテリー` `CylinderGeometry(0.0035, 0.0035, 0.0060)`、
  `基板` `BoxGeometry(0.0110, 0.0016, 0.0070)`、`マイク` `CylinderGeometry(0.0012, 0.0012, 0.0010)`。
- **台座**（明転章）: `CylinderGeometry(0.052, 0.054, 0.008, 64)`、マット白。接地影（放射グラデーションの板）は台座天面より 0.7mm 上に置く（同じ高さだと干渉して星形のノイズが出る）。

### 3-4. スクロールのタイムライン（章に合わせて配置する）
ページ全体の進捗 p = scrollY / (最後の章の下端 − 1画面)。章は 450svh × 6 なので、
**章 i が sticky で見えているのは p ≈ [i×450/2600, (i×450+350)/2600]**（ch0 0〜0.135 / ch1 0.17〜0.31 /
ch2 0.35〜0.48 / ch3 0.52〜0.65 / ch4 0.69〜0.83 / ch5 0.87〜1.0）。**見せ場は各章の中央に置く**。

| p | カメラ位置 | 注視点 | 蓋 | 取り出し | 分解 | 明るさ | 回転 | 見せ場 |

| 0.00 | (0.000, 0.050, 0.340) | (0, 0.000, 0) | 0.00 | 0.00 | 0.0 | 0.00 | 0.00 | 01 CASE |
| 0.12 | (0.090, 0.062, 0.270) | (0, 0.002, 0) | 0.20 | 0.00 | 0.0 | 0.00 | 0.30 | |
| 0.24 | (0.160, 0.090, 0.215) | (0, 0.010, 0) | 1.85 | 0.15 | 0.0 | 0.00 | 0.75 | 02 OPEN |
| 0.41 | (0.085, 0.078, 0.190) | (0, 0.030, 0) | 1.85 | 1.00 | 0.0 | 0.00 | 1.15 | 03 FIT |
| 0.53 | (0.130, 0.052, 0.168) | (0, 0.036, 0) | 1.85 | 1.00 | 0.35 | 0.00 | 1.55 | |
| 0.60 | (0.150, 0.040, 0.150) | (0, 0.038, 0) | 1.85 | 1.00 | 1.0 | 0.00 | 1.90 | 04 INSIDE |
| 0.68 | (0.030, 0.068, 0.205) | (0, 0.032, 0) | 1.40 | 1.00 | 0.2 | 0.35 | 2.30 | |
| 0.76 | (-0.080, 0.075, 0.260) | (0, 0.028, 0) | 0.60 | 1.00 | 0.0 | 1.00 | 2.75 | 05 LIGHT |
| 0.94 | (0.100, 0.045, 0.205) | (0, 0.034, 0) | 0.00 | 1.00 | 0.0 | 1.00 | 3.25 | 06 COLOR |
| 1.00 | (0.000, 0.050, 0.320) | (0, 0.020, 0) | 0.00 | 1.00 | 0.0 | 1.00 | 3.55 | |

- 区間内は `smoothstep` で補間。角度は rad。
- **縦長画面の補正**: `aspect < 1` のとき、注視点からカメラまでの距離を `(1/max(0.5, aspect))^0.8` 倍に伸ばす
  （390×844 では約 1.6 倍）。これをしないと製品が画面から溢れる。
- **回転（重要）**: 製品の `rotation.y` も**キーフレームで持つ**（表の「回転」列, rad）。
  スクロール量に比例させて回し続けると動きは出るが、見せ場ごとの向きが運任せになる。
  キーで持てば「動きは続くのに、各章では良い角度で止まる」。これに毎フレーム `+0.0006rad` の微速回転を足す。
- **左右の寄せ**: テキストが左の章では製品を右（x +0.055）、右の章では左（x −0.055）へ寄せる。
  <640px では左右に寄せず、上へ（y +0.020、分解中はさらに +0.014）寄せてテキストと上下に分ける。
- **分解中はケースを退場させる**: ケース（本体・蓋・合わせ目）を1つの Group にまとめ、`y -= 0.10 × 分解量`。
  ケースが残っていると、主役のイヤホンより大きくて目立ってしまう。
- **取り出し**: 0→1 でイヤホン 2 個が `y +0.035`、左右へ `x ±0.011` 離れ、`rotation.y` が `±0.6rad` 回る。
- **分解**: 0→1 で ノズル `(±0.018, −0.012)`、チップ `(±0.030, −0.020)`、リング `y +0.016`、
  ドライバー `z +0.020`、バッテリー `x ∓0.022`、基板 `y −0.020`。分解中はシェルの不透明度を 1 → 0.45 に、
  内部パーツを 0 → 1 にする。
- **常時**: ケース群を `rotation.y += 0.0016 rad/frame`（reduced-motion では止める）。

### 3-5. 分解図のラベル（DOM を 3D に貼る）
- 分解章（**p 0.54〜0.66**）でだけ表示。ラベル 4枚: `10mm ドライバー` / `ハイブリッドANC マイク` / `24時間ぶんのバッテリー` / `4.3g のシェル`。
- **ラベルは画面左に縦一列**（x = 48px、y = 画面高の 26% / 40% / 54% / 68%）に固定し、
  そこから対応パーツへ **SVG の 1px の線**を引く。線の始点はラベルの右端、終点はパーツのワールド座標を
  `camera.project()` で毎フレーム画面座標へ変換した点。
  （ラベルを部品の周りに散らすと、右側に置いた章テキストと必ず衝突する。左の一列に固定すると衝突しない。）
- 表示は `opacity` を進捗でフェード（`0.54→0.58` で入り、`0.63→0.66` で抜ける）。1枚ごとに 0.006 ずつ遅らせる。
- パーツがカメラの後ろ（`z > 1`）に回ったラベルは隠す。
- <640px ではラベルを出さない（章テキストと領域が重なるため）。

## 4. 章とコピー（`<main>`、各 `height: 450svh` / 内側 sticky）

`c > 0.78` で抜ける（逆再生）。`transition` ではなく**スクロール量から直接スタイルを書く**（参照サイトと同じ scrub）。

## 5. 常設 UI

- **ヘッダー**（fixed）: 左 `SOTTO`、右に `¥29,800` と `購入する`（#buy へ）。暗転中は白文字、明転中は黒文字（`--fg` を継承）。
- **章インジケータ**（右端 fixed、≥1024px）: 6個の点と章ラベル。現在の章は `--accent` で塗り、点の間の線が章内の進捗で伸びる。クリックでその章へ `lenis.scrollTo`。
- **スクロールキュー**（最初の1画面だけ）: `SCROLL` の文字と、下へ流れる 1px の光点。p > 0.02 で消える。

## 6. 性能・アクセシビリティ

- 直近 60 フレームの平均が 24ms を超えたら DPR を 1 → 0.75 に一度だけ落とす。`visibilitychange` で描画停止。
- `prefers-reduced-motion: reduce`: 自動回転なし、章テキストは常時表示、ラベルのフェード遅延なし、カラー切替は即時。
- WebGL が取れないときは canvas を隠し、`body` に暗→明のグラデーションを敷いて**文字だけで読める**ようにする。
- 3D は `aria-hidden="true"`。スペックは `<dl>` として読める。カラー切替は `aria-pressed` を持つ `<button>`。

## 7. 受け入れ条件

1. 1440×900 / 390×844 でコンソールエラー 0、横スクロールなし、アンカー切れなし。
2. スクロールすると **ケースが開き → イヤホンが浮き → 分解してラベルが付き → 組み直して明転 → 色を選べる** 流れが、静止画の並びだけで読み取れる。
3. 分解章のラベルが、対応する部品の近くに線でつながって表示される（部品から離れた位置に飛ばない）。
4. 明転の前後で背景色・文字色・ヘッダーの色が破綻しない（白地に白文字が出ない）。
5. カラー切替で 3色がはっきり見分けられる。ドラッグで製品が回る。
6. 390px で章テキストが製品に重ならない（テキストは下半分、製品は上半分に寄せる）。
7. 単一 `index.html`。外部の画像・動画・3Dモデルを使わない。
